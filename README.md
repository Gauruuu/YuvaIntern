## 📌 Executive Portfolio Overview

This repository contains the complete, production-grade 4-week deliverables developed for the **Yuva Intern Data Science Internship**. Across all four weeks, the project follows a cohesive, industry-relevant enterprise problem:

> **OmniChurn AI**: An end-to-end predictive customer churn intelligence and dynamic retention optimization platform engineered for a high-growth FinTech and B2B SaaS organization (45,000 corporate clients, $12,000 average ARR, $36.72M annual churn exposure).

By replacing legacy reactive firefighting with an algorithmic early-warning radar, OmniChurn AI delivers:
* **Gross Churn Reduction:** From 6.8% down to **4.6%** (-32.3% relative reduction).
* **Net Preserved ARR:** **$11.41 Million** in protected recurring revenue in Year 1.
* **Frontline Conversion:** Elevating Customer Success outreach conversion from **18% to 42.5%**.
* **Annualized Net ROI:** **2,450%** return on an infrastructure investment of $145,000.

2. **Create a New Repository on GitHub:**

3. **Link Remote and Push:**
   ```bash
   git remote add origin https://github.com/<your-username>/YuvaIntern-DataScience.git
   git branch -M main
   git push -u origin main
   ```
